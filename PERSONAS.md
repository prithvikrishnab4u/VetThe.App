Personas
========

1) Identity Engineer
- Role: Chooses and configures SSO/SCIM/MFA for company apps.
- Needs: Precise protocol support, provisioning details, MFA types, implementation notes.
- Success: Reduces integration time and avoids security gaps.

2) IT Procurement Manager
- Role: Evaluates vendors for contracts and pricing.
- Needs: Feature checklist, tier mapping, compliance certifications, comparative view.
- Success: Faster RFP responses and vendor shortlisting.

3) Security Reviewer / Auditor
- Role: Reviews vendor security posture and maintains audit records.
- Needs: Provenance, verification badges, compliance evidence, exportable reports.
- Success: Clear, auditable documentation for compliance checks.
