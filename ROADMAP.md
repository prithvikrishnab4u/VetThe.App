Implementation roadmap
======================

Phase 1 — MVP (completed or in progress):
- Structured YAML app data + schema
- Validation script and CI check
- Generated JSON/CSV exports
- Basic Hugo site and Cloudflare Pages deploy

Phase 2 — Polish (next 1-2 sprints):
- Comparison UI with filtering and multi-select
- Provenance badges and evidence links
- Contributor guidelines and governance
- Add analytics and usage reporting

Phase 3 — Automation & scale:
- Automated vendor verification (APIs, doc scraping)
- Programmatic integrations and SDKs
- Badge/vetting program and community onboarding
